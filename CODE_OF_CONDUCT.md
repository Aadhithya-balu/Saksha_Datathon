# Contributor Covenant Code of Conduct

## Our Pledge

We as members, contributors, and maintainers pledge to make participation in the Saksha project a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

We pledge to act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy development environment.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Demonstrating empathy and kindness toward others.
- Being respectful of differing opinions, viewpoints, and experiences.
- Giving and accepting constructive feedback professionally.
- Accepting responsibility for mistakes and learning from them.
- Prioritizing the success of the project over personal preferences.
- Writing clean, maintainable, and well-tested code.
- Respecting established architecture, coding standards, and review processes.

Examples of unacceptable behavior include:

- Harassment, discrimination, intimidation, or personal attacks.
- The use of sexualized language or imagery.
- Trolling, insulting, or derogatory comments.
- Publishing another person's private information without permission.
- Deliberately introducing malicious, destructive, or misleading code.
- Knowingly bypassing project rules or review processes.

---

# AI-Assisted Contributions

Saksha welcomes AI-assisted software development.

Contributors using AI tools (such as ChatGPT, Codex, Claude, Gemini, Cursor, GitHub Copilot, Windsurf, etc.) are fully responsible for all generated code.

All AI-assisted contributions must:

- Follow the project's architecture.
- Follow the rules defined in `agent_rules.md`.
- Preserve existing functionality.
- Avoid unnecessary refactoring.
- Avoid unrelated modifications.
- Be manually reviewed before submission.
- Be tested before creating a Pull Request.

AI-generated code is subject to the same review standards as manually written code.

---

# Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing the standards of acceptable behavior.

Maintainers may remove, edit, or reject comments, commits, pull requests, issues, or other contributions that are not aligned with this Code of Conduct.

Reasons for moderation decisions will be communicated when appropriate.

---

# Scope

This Code of Conduct applies to all project spaces, including:

- GitHub repositories
- Pull Requests
- Issues
- Discussions
- Documentation
- Team communication channels
- Project demonstrations
- Community events

It also applies whenever an individual is officially representing the Saksha project.

# Enforcement Guidelines

Community leaders will follow these Community Impact Guidelines when determining consequences.

## 1. Correction

**Community Impact**

Minor inappropriate behavior or unprofessional conduct.

**Consequence**

A private written warning explaining the violation and expected behavior.

---

## 2. Warning

**Community Impact**

Repeated inappropriate behavior or a more significant violation.

**Consequence**

A formal warning and temporary restrictions on project interactions.

---

## 3. Temporary Ban

**Community Impact**

Serious violations including repeated harassment or disruptive conduct.

**Consequence**

Temporary suspension from contributing to the project.

---

## 4. Permanent Ban

**Community Impact**

Repeated violations, harassment, malicious behavior, or conduct that seriously harms the community or project.

**Consequence**

Permanent removal from all project participation.

---

# Engineering Principles

All contributors should strive to:

- Preserve project stability.
- Respect module ownership.
- Keep Pull Requests focused.
- Avoid unnecessary merge conflicts.
- Write production-quality code.
- Maintain backward compatibility whenever possible.
- Follow the project's documentation and contribution guidelines.
